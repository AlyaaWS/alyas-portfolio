Sales Analysis Dashboard

Year 2025
Role BI Analyst Intern
Link GitHub Repository

Project Description

Businesses often struggle to make sense of fragmented sales data. The goal of this project was to transform raw, unstructured sales data from various sources into actionable business insights.

I developed a comprehensive data analysis pipeline that cleans and processes data, resulting in an interactive Looker Studio dashboard that visualizes sales performance and helps stakeholders make data-driven decisions.

My Contribution

I handled the entire data pipeline: from extracting and cleaning the raw data using SQL and Excel, to designing the final interactive visualization in Looker Studio. I focused on creating clear metrics like total revenue, regional performance, and product trends.

What I Learned

This project sharpened my analytical thinking and taught me how to communicate technical data findings to non-technical stakeholders visually. I learned that good data visualization is not just about charts, but about telling a clear, actionable story.
