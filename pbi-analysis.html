Sales Analysis Dashboard

Year 2025
Role BI Analyst Intern
Link GitHub Repository

Project Description

Businesses often need a clearer view of sales performance across multiple data sources to support informed decision-making. This project focused on transforming sales data into actionable business insights through data processing, analysis, and visualization.

I developed a data analysis pipeline using SQL and BigQuery to consolidate sales data into master tables, followed by an interactive Looker Studio dashboard that visualizes sales performance across product categories, regions, and transaction trends.

My Contribution

I processed sales data from multiple sources using SQL and BigQuery to build master tables for analysis. I then designed and developed an interactive Looker Studio dashboard to highlight key sales metrics, regional performance, product categories, and transaction trends. I also derived business insights and recommendations to support data-driven decision-making.

What I Learned

This project strengthened my analytical thinking and my ability to translate sales data into meaningful business insights. I gained experience in data preparation, SQL-based analysis, and dashboard development, while learning how effective data visualization can help communicate findings and support business decisions.
