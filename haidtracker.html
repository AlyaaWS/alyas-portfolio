Class Project

Haidtracker

Year 2024
Role Full Stack Developer

Project Description

HaidTracker is a web-based menstrual cycle tracking application designed to help users monitor their menstrual cycles and predict upcoming periods based on their cycle history. The application also provides relevant educational articles tailored to users' reported symptoms, helping them better understand their menstrual health.

Developed as a college project, HaidTracker adopts a Software-as-a-Service (SaaS) model with pricing options for its services, combining menstrual cycle tracking, personalized content, and a user-friendly interface in one platform.

My Contribution

As a Full Stack Developer, I contributed to the development of HaidTracker using Laravel, PHP, and MySQL. I worked on the application's core functionality, including menstrual cycle tracking, period prediction, symptom-based article recommendations, and the supporting database structure.

What I Learned

This project strengthened my understanding of full-stack web development using Laravel, PHP, and MySQL. I gained experience in developing application features around user input and stored data, while exploring how personalized content and a SaaS business model can be incorporated into a web-based application.

Visual Story

Cycle Logging & Health Notes Dashboard
Menstrual Tracking & Health Insights

An intuitive dashboard interface that allows users to select and log their period dates using an interactive calendar, record daily moods and physical symptoms (such as cramps and nausea), receive automated predictions for upcoming cycles along with health condition assessments, and explore curated educational articles supporting reproductive wellness.
