Group Project

MEDIPULSE

Year 2024
Role Backend Developer
Link GitHub Repository

Project Description

MEDIPULSE is a medication reminder and tracking web application developed as a group project during the Independent Study Program at Rakamin Academy.

The application was designed to help users manage medication schedules and track their medication routines. It also includes a feature for BMI analysis supported by machine learning integration.

My Contribution

As a Backend Developer, I contributed to the backend development of MEDIPULSE and worked with the team to integrate application features. I also contributed to the integration of the machine learning component used for BMI analysis.

I collaborated with other team members throughout the development process and used Git for version control and code collaboration.

Technical Approach

The project focused on developing the application's backend functionality and integrating the different components required for medication scheduling and tracking.

A machine learning component was integrated to support BMI analysis, allowing the application to provide additional analysis based on user data. Git was used to manage code changes and support collaboration within the development team.

Impact

MEDIPULSE provided a digital solution for organizing medication schedules and tracking medication routines in one application. The addition of BMI analysis also extended the application beyond basic medication reminders by providing supporting health-related analysis.

What I Learned

Working on MEDIPULSE strengthened my understanding of backend development and collaboration within a software development team. I gained experience working with different application components and integrating a machine learning feature into a web application.

The project also improved my experience with Git-based collaboration and helped me understand how backend functionality can support features developed across different parts of an application.
