Class Project

Makeup Marketplace

Year 2023
Role Full Stack Developer
Link GitHub Repository

Project Description

The project aimed to create an end-to-end e-commerce experience tailored specifically for cosmetic products.

It is a full-featured marketplace website complete with a product catalog, category filtering, a shopping cart system, and payment gateway integration to support seamless user transactions.

My Contribution

I developed the application using CodeIgniter and MySQL. My work included designing the database for products and orders, building the user interface, implementing the shopping cart logic, and integrating the Midtrans payment gateway for processing transactions.

What I Learned

This project provided hands-on experience with MVC frameworks (CodeIgniter) and third-party API integration. I learned how to handle complex application states like cart sessions and secure payment handshakes.
